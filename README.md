# 🧠 Kogito — Jogo Educacional para Pessoas com Deficiência Intelectual

Kogito é um jogo educacional em formato de quiz desenvolvido como Trabalho de Conclusão de Curso no Instituto Federal Catarinense. O sistema foi criado para apoiar o ensino de lógica computacional a estudantes com deficiência intelectual, com progressão gradual de dificuldade, feedback imediato e controle de progresso por usuário.

> 🎓 Projeto testado com usuários reais, demonstrando melhora no raciocínio lógico e maior autonomia durante o uso.

---

## 🎮 Sobre o Jogo

- Sistema de quiz com múltiplas fases
- Progressão gradual de dificuldade
- Feedback imediato nas respostas
- Elementos visuais para melhor acessibilidade
- Progresso salvo por usuário — o jogador pode continuar de onde parou

---

## 🚀 Getting Started

### Prerequisites

- Node.js 18+
- MySQL

### Installation

```bash
git clone https://github.com/vitorcordioli/Kogito-Jogo.git
cd Kogito-Jogo
npm install
```

### Environment Setup

Crie um arquivo `.env` dentro da pasta `backend/`, igual o do .env.example

### Running

```bash
cd jogotcc
npm run start
```

O servidor estará disponível em `http://localhost:3000`

---

## 🛠️ Tech Stack

- **Runtime:** Node.js
- **Framework:** Express.js
- **Banco de dados:** MySQL
- **Autenticação:** JWT + bcrypt
- **Segurança:** helmet, express-validator
- **Frontend:** HTML, CSS, JavaScript
